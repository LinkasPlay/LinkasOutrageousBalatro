# Linkas' Outrageous Balatro

A massive and creative Balatro mod designed to make every run unique and unpredictable. Heavily inspired by my university experience at CY Tech, this mod integrates numerous references to student life, scientific subjects, and teaching staff, all while keeping the core Balatro spirit.

## Mod Content

* **90 New Jokers**: A huge collection divided into several thematic categories (Student Jokers, Professor Jokers, Computer Science, Mathematics, Physics...).
* **10 New Legendary Jokers**: Accessible through a brand new fusion mechanic. You need to obtain and combine a new Spectral card, the "Lukas' Ritual", with a Student Joker to awaken the corresponding Legendary Joker.
* **New Decks and Challenges**: Fresh ways to start a run, waiting to be discovered in-game.
* **New Consumables and Upgrades**: Added new Tarots, Spectral cards, as well as new Enhancement types and Editions for your cards.

## Vision and Balance

This mod is not meant to be perfectly balanced. The main goal is fun and diversity:
* You will find very "vanilla-like" Jokers that blend smoothly into the base mechanics.
* Other Jokers are deliberately designed to break the game. Some gimmicks are so deep they will make you feel like you are playing a completely different game.

## Installation

1. Make sure you have [Steamodded](https://github.com/Steamodded/smods) installed and working on your copy of Balatro.
2. Download the latest release of this mod from the Releases tab on GitHub.
3. Extract the downloaded folder and place it directly into your Balatro mods directory (usually located at `%AppData%\Balatro\Mods` on Windows).
4. Launch the game and enjoy.
